# PowerTimer ⏱️

**PowerTimer v0.8.0 Stable** · Windows 11 x64 · Tauri 2 / Rust

Портативный таймер системных действий Windows с современным тёмным интерфейсом, режимом предварительной проверки и управлением через системный трей.

**[Скачать PowerTimer v0.8.0](https://github.com/TraurigerEngel/PowerTimer/releases/tag/v0.8.0)** · [Описание релиза](RELEASE_NOTES_0.8.0.md) · [Проверки Windows](QA_WINDOWS_RU.md)

## Возможности

- Четыре действия: **выключение**, **перезагрузка**, **блокировка** и **выход из учётной записи**.
- Четыре способа запуска: **интервал**, **заданное время**, **бездействие** и **низкая загрузка процессора**.
- Предупреждение и отмена перед выполнением действия, индикатор прогресса.
- **Тестовый режим** для проверки таймера без выполнения системных действий.
- Управление из системного трея, локальный журнал и сохранение настроек.
- Фиксированное окно 1200 × 680, собственная строка заголовка, тёмная тема с мягкими акцентами.

Сон и гибернация отсутствуют — доступны только четыре перечисленных действия.

## Установка

1. Откройте [релиз v0.8.0 Stable](https://github.com/TraurigerEngel/PowerTimer/releases/tag/v0.8.0).
2. Скачайте **`PowerTimer_v0.8.0_Stable_Portable.zip`**.
3. Распакуйте его в отдельную папку и запустите **`PowerTimer.exe`**.

Проверка Portable на Windows 11 подтверждена пользователем. Для безопасного знакомства с функциями используйте тестовый режим.

Готовый EXE не требует установленного Node.js или Rust, но использует **Microsoft WebView2 Runtime**. При переносе настроек сохраняйте свой `config.ini` отдельно.

## Безопасное использование

> **Для проверки таймера включайте «Тестовый режим».** Выключение, перезагрузка или выход из учётной записи в обычном режиме действительно могут завершить сеанс Windows и привести к потере несохранённой работы.

Таймер не восстанавливает активный отсчёт после полного выхода из приложения или перезапуска компьютера. Проверку работы в Windows проводите по [QA_WINDOWS_RU.md](QA_WINDOWS_RU.md).

## Сборка из исходников

Понадобятся **Node.js**, npm, **Rust/MSVC**, Windows SDK и компоненты сборки Tauri 2.

```powershell
npm.cmd install
npm.cmd run check
cargo test --manifest-path .\src-tauri\Cargo.toml
npm.cmd run build
```

Готовый файл: `src-tauri\target\release\powertimer.exe`.

Для полного релизного цикла предусмотрен скрипт:

```powershell
.\MAKE-FINAL-RELEASE.ps1
```

Сборка из опубликованных исходников использует **Inter, установленный в Windows**, либо системный шрифт. Шрифтовые бинарные файлы не входят в GitHub-копию; это может немного отличаться по типографике от готового оригинального EXE. Готовый EXE для GitHub Release сохранён без изменений.

## Конфиденциальность и файлы пользователя
