# PowerTimer v0.8.0 Stable ⏱️

Портативный таймер системных действий для Windows 11 x64. Работает как отдельный EXE на Tauri 2 / Rust при наличии Microsoft WebView2 Runtime.

## Что умеет

- Выключение, перезагрузка, блокировка и выход из учётной записи.
- Запуск по интервалу, определённому времени, бездействию или низкой загрузке CPU.
- Предупреждение и отмена, прогресс выполнения, **тестовый режим**.
- Работа через трей, настройки и локальный журнал событий.
- Тёмный интерфейс, 1200 × 680, утверждённое оформление RC5.
- Исправленная надёжность конфигурации, расписания и предупреждений.

## Установка

1. Скачайте `PowerTimer_v0.8.0_Stable_Portable.zip` из Assets.
2. Распакуйте ZIP и запустите `PowerTimer.exe`.
3. Для безопасного знакомства включите **«Тестовый режим»**.

## Безопасность

В обычном режиме системные действия реальные. Сохраните документы перед использованием; для проверки функций не выключайте тестовый режим.

Пользовательские файлы `config.ini` и `Logs/` не включены в архив исходников или Portable ZIP.

**Оригинальный EXE не изменён относительно предоставленной версии v0.8.0 Stable.** Пользователь подтвердил успешную проверку Portable на Windows 11, включая окно, трей, настройки, предупреждение и отмену в тестовом режиме. Новая сборка Rust из GitHub-исходников отдельно не выполнялась.
