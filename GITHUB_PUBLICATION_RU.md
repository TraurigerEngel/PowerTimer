# PowerTimer 0.8.0 — публикация на GitHub

- В репозиторий добавлены только исходники (без `config.ini`, `Logs`, собранных EXE и файлов шрифтов).
- Используется подтверждённый релизный исходный архив версии `0.8.0`.
- Готовый Portable ZIP содержит ровно один оригинальный `PowerTimer.exe` и не пересобирается.
- Для проверки таймера включайте **«Тестовый режим»** — реальные системные операции не нужны для тестов.
- GUI, трей, Windows-специфичный код и Rust unit tests необходимо проверять на Windows 11 при новой сборке из исходников.
- В исходной UI-разметке трея сохранилось историческое обозначение `0.8 RC3` — оно присутствует в исходном Stable-выпуске; это не Pre-release в GitHub и не меняет версию `0.8.0` Tauri. Оригинальный EXE оставлен побайтно прежним.

Осторожно: если впоследствии меняете интерфейс или шрифтовые файлы исходников, новая сборка может выглядеть не точно так же, как ранее выпущенный бинарник.
